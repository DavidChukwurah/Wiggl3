# wiggl3 continuity log (v6, version 0.3.0)

Date: 2026-10-22. Supersedes v5. Full rebuild from scratch with a real compiler (Rust 1.98.1) in the sandbox.

## Product
wiggl3 glides the cursor when the user is idle so chat apps do not show Away and the screen stays awake. Window with on/off,
interval (15 s to 4 min), duration (forever, 1/2/4/8 h, custom range); tray / menu bar icon (Open, Pause/Resume, Quit);
notifications; one instance; closing hides to the tray. Platforms: Windows 10/11 x64, macOS 11+ (universal), desktop Linux
glibc 2.28+ (x86_64 and aarch64; X11 and Wayland). Details: README.md, SUPPORTED-PLATFORMS.md.

## What changed from v5
- **Colour:** all green removed (never approved). Greys only; toggle on = pale (dark mode) or near-black (light mode); red remains only for the
  outline of an invalid date/time field. Accent is a single place (`ui/theme.rs`, `track_on`/`knob_on`) if a colour is chosen later.
- **Logo:** Material Symbols `pest_control_rodent` (Apache 2.0). App icon = outlined glyph, pale on a dark tile. Tray icons = filled glyph, no background
  (macOS template; Windows light/dark by taskbar theme; Linux outlined). Regenerated by `tools/make_icon.py`.
- **Distribution:** no Git for users. Stable-named release assets (`releases/latest/download/...`), rolling "latest" release on every push to main,
  `docs/index.html` download page (GitHub Pages), `PUBLISHING.md` browser-only steps. Linux = `.tar.gz` with per-user installer (AppImage dropped: needs FUSE 2,
  missing on current Ubuntu), built in a manylinux_2_28 container (glibc 2.28 floor), plus an aarch64 job (allowed to fail). One pinned Rust (1.98.1).
- **Bugs found and fixed (by reading winit 0.30 and testing):**
  1. Native Wayland cannot hide a window (`set_visible` is a no-op), so close-to-tray did nothing. Now the window is created through XWayland when available;
     otherwise `can_hide` is false and closing quits.
  2. A hidden window is probably not redrawn on Windows, which stalled tray clicks / state / second-copy wake. Tray is now callback-driven; Windows uses
     `ShowWindow` directly and a 500 ms `SetTimer`; second-copy detection has its own thread (token content, not file time).
  3. f32/f64 literal fallback is a future hard error; fixed. Rust pinned in CI.
  4. macOS never prompted for Accessibility; now `AXIsProcessTrustedWithOptions` prompt once per launch.
  5. Keep-awake failures were shown as user errors; now logged only.
  6. Wayland idle time is read from GNOME Mutter / KDE over D-Bus (v5 moved every interval regardless).
  7. Settings are written atomically; doctor no longer asks for dev libraries (none are needed to build).
- Tray Quit now removes the icon and exits directly (avoids a Windows ghost icon).

## Risks
First CI run can need fixes (container build, macOS lipo/dmg, release step). macOS: hidden-window redraw is assumed from winit source; the tray refresh heartbeat is untested.
Unsigned apps trigger SmartScreen / Gatekeeper warnings and may be blocked on managed computers. Name-collision check for "wiggl3" still not done.
